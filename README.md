# Калькулятор ландшафтных работ «Петербургские газоны»

Веб-приложение для расчета стоимости ландшафтных работ с автоматической генерацией коммерческого предложения (PDF) и отправкой его клиенту на email.

📋 Возможности

· Интерактивный расчет стоимости (газон, подготовка, доставка, доп. услуги).
· Автоматическая генерация PDF-файла (Коммерческое предложение) с помощью Google Docs.
· Отправка PDF на почту клиенту.
· Отправка уведомления менеджеру о новой заявке.
· Сохранение всех заявок в Google Таблицу (база данных).

📁 Структура проекта

· index.html — основной файл разметки сайта.
· style.css — стили оформления.
· script.js — логика работы калькулятора и отправка данных на сервер.
· код для gas.txt — скрипт для Google Apps Script (серверная часть).

---

🚀 Инструкция по развертыванию с нуля

Для работы проекта нужны две части: сайт (фронтенд) и Google Apps Script (бэкенд, который делает PDF и рассылает письма).

Шаг 1: Создание базы данных (Google Таблица)

1. Зайдите на Google Диск.
2. Создайте новую Google Таблицу и назовите её ровно так: Заявки с калькулятора (имя должно совпадать символ в символ, иначе скрипт не найдет файл).
3. В первой строке (шапке) можно создать заголовки: Дата, Email клиента, Услуги, Итого.

Шаг 2: Настройка Google Apps Script (GAS)

1. Перейдите на сайт script.google.com и создайте Новый проект.
2. Откройте файл код для gas.txt из этого репозитория, скопируйте весь код.
3. Вставьте код в редактор GAS, полностью заменив то, что там было по умолчанию.
4. В коде найдите строку to: 'maksimvoroshilin1999@gmail.com', (примерно 67-я строка) и убедитесь, что там указан email менеджера, которому должны приходить уведомления.
5. Нажмите значок дискеты 💾 (Сохранить).

Шаг 3: Развертывание (Публикация) скрипта

1. В правом верхнем углу нажмите кнопку «Начать развертывание» (Deploy) -> «Новое развертывание».
2. Нажмите на шестеренку ⚙️ (Выберите тип) и выберите «Веб-приложение».
3. Заполните поля:
   · Описание: Калькулятор (или любое другое).
   · Запуск от имени: Я (ваш аккаунт).
   · У кого есть доступ: Все (Anyone).
4. Нажмите «Развернуть».
5. ВАЖНО: Система попросит предоставить разрешения. Нажмите «Предоставить доступ» -> выберите аккаунт -> нажмите «Дополнительно» -> «Перейти на страницу (небезопасно)» -> «Разрешить». (Скрипту нужен доступ к вашей почте, диску и таблицам).
6. Скопируйте URL-адрес веб-приложения (длинная ссылка, заканчивающаяся на /exec).

Шаг 4: Настройка сайта (Фронтенд)

1. Откройте файл script.js.
2. Найдите в самом начале кода константу GAS_URL (примерно 37-я строка).
3. Замените текущую ссылку на ту, которую вы скопировали на Шаге 3. Должно получиться так:
   ```javascript
   var GAS_URL = 'https://script.google.com/macros/s/ВАШ_НОВЫЙ_ИДЕНТИФИКАТОР/exec';
   ```
4. Сохраните файл.

Шаг 5: Запуск

1. Загрузите файлы index.html, style.css и script.js на любой хостинг.
2. Самый простой и бесплатный вариант — использовать GitHub Pages (в настройках репозитория в разделе Pages выберите ветку main и папку /(root)).
3. Откройте сайт в браузере, введите площадь, выберите услуги, укажите email и нажмите «Отправить».

---

⚠️ Важные нюансы

· Лимиты Google: Обычный аккаунт Gmail может отправлять до 100 писем в сутки через скрипты. Если нужно больше — потребуется Google Workspace.
· Редактирование кода: Если вы вносите изменения в код GAS, вы обязаны создавать «Новую версию» при развертывании (Deploy -> Manage Deployments -> ✏️ (карандаш) -> Version: New version -> Deploy). В противном случае Google продолжит работать по старому коду.
· Мобильный редактор: Редактор GAS на смартфонах часто ломает код при вставке (выкидывает скобки, переносит строки). Рекомендуется вносить изменения с компьютера.
